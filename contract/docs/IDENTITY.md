# IDENTITY — идентичность нод

Нормативно. Фиксирует **текущий развёрнутый** алгоритм (редизайн запрещён —
инвалидирует пользовательские отметки; SPEC 103, не-цели). Эмпирика: кросс-прогон
14 форм нод дал байт-идентичный хеш в 10 — расхождения §3 закрываются в фазе 2.

## 1. Identity-хеш (общий для обоих проектов)

```
identity_hash = hex( sha256( compact_json( deep_sort_keys( emit(node) − tag − detour ))))
```

- `emit(node)` — канонический sing-box map узла (для endpoint-схем — endpoint-JSON;
  переменные шаблона на emit не влияют);
- исключаются ровно два поля верхнего уровня: `tag`, `detour`;
- `deep_sort_keys` — рекурсивная сортировка ключей map; порядок списков сохраняется;
- `compact_json` — без пробелов, **без escaping** (D-007, CANON §2.7);
- результат — 64 символа lowercase hex, без префикса;
- невозможность эмиссии → пустая строка = «нет идентичности», нода не участвует
  в дедупе/отметках.

Реализации: Go `core/config/node_hash.go` (`NodeIdentityHash`);
Dart `app/lib/services/node_hash.dart` (`nodeIdentityHash`).

## 2. Использования (симметрично, SPEC 101)

Дедуп в пределах источника; владение идентичностью между элементами Xray-массива;
ссылки групп на членов; привязка detour-ноды; ключи disabled-отметок.

## 3. Расхождения хеша — закрыты

| Класс | Причина | Решение |
|---|---|---|
| строки с `<>&` (и ` /29`) | Go HTML/юникод-escaping | Go → без escaping (D-007) ✅ |
| ws `?ed=N` без `eh` | Dart не эмитил `early_data_header_name` | Dart добавил дефолт `Sec-WebSocket-Protocol` (D-008) ✅ |
| anytls без `fp=` | Go не эмитил utls | Go добавил дефолт `random` по vless-конвенции (D-009) ✅ |
| wireguard | Go эмитил `name`/`system` | Go убрал дефолтные поля (D-010) ✅ |

### 3.1 Защита от возврата

Каждое расхождение закрыто тестом — проза сама по себе регрессию не ловит:

- Go: `core/config/identity_contract_test.go` — `TestIdentityNoHTMLEscaping`,
  `TestIdentityWSEarlyDataHeaderPresent`, `TestIdentityWireGuardNoDefaultFields`,
  плюс инварианты §1 (tag не входит в хеш, разные ноды различимы, хеш стабилен
  между вызовами и имеет форму 64 lowercase hex).
- Общий корпус `corpus/uri/**` прогоняется обеими сторонами: расхождение
  эмиссии проявится как разъехавшийся `expected` ещё до хеша.


Миграция: отметки затронутых нод истекают по штатному TTL (§5), пересопоставление
не строится (D-014).

## 4. By-design различие: nodeIdentityKey (только LxBox)

Dart дополнительно использует строковый ключ `protocol|server|port|credential`
(без транспорта и TLS): ноды одного сервера с разными SNI **схлопываются** на
мобиле и **не схлопываются** на десктопе (Go сознательно живёт одним хешом —
`node_hash.go:14-25`). Различие остаётся: в корпусе — per-app override
(CANON §7); на переносимость disabled-отметок не влияет (они по хешу).

На мобиле хеш считается от ноды **после** import-rules §302 (`patchedJson`) —
отметки патченных нод с десктопом не совпадают (честное ограничение, BACKUP.md).

## 4a. Законные per-app override'ы корпуса

`corpus/README.md` требует, чтобы каждый `<case>.expected.lxbox.json` ссылался
на задокументированное различие, иначе он — мусор для линтера. Аудит 25.08
(контракт 0.8.0) прошёл все override'ы: из 281 содержательными оказались 24,
остальные 257 были побайтовыми копиями базы и снесены. Оставшиеся делятся на
три класса — ссылаться следует сюда.

**A. Warning есть у Dart, у Go запланирован** — `tls_insecure` (10 кейсов),
`ech_ignored` (3), `utls_fp_unknown` (1), `vision_with_transport` (2).
В `registry/warnings.json` у этих кодов `"go": null` либо описан разрыв: Go
сегодня деградирует молча, целевое поведение — по Dart. Override исчезнет,
когда лаунчер заведёт warning-аккумулятор; база при этом не меняется.

**B. Desktop-only поля entry** — `ssh` `client_version` и `private_key_path`
(2 кейса). Помечены `"ext": "desktop"` в `registry/protocols/ssh.json`:
путей файловой системы на мобиле нет by design, поле не парсится и в конверт
не попадает. Постоянное различие, не подлежит выравниванию.

**C. Неканоничная схема в базовых ожиданиях** — `socks` (6 кейсов). Канон
(CANON §1) требует `scheme` из `registry/protocols/socks.json` → `"socks"`;
Dart отдаёт `socks`, базовые `.expected.json` пишут `socks5` (это алиас, а не
канон). Override фиксирует каноничное значение. **Чинить в базе на стороне
лаунчера**; после этого override снимается. Зеркальный случай `shadowsocks`
закрыт со стороны LxBox: раннер канонизирует внутреннее имя протокола в
`ss` (`_canonScheme` в `test/contract/contract_test.dart`), 8 override'ов
снято.

## 5. Disabled-отметки

- Ключ — identity-хеш; значение — lastSeen.
- Форматы значений в хранилищах приложений различны (Go unix int64,
  Dart ISO-8601) — **в обменном формате бэкапа всегда unix seconds** (D-014).
- TTL общий: `clamp(3 × interval_hours, 24h, 720h)`; interval ≤ 0 → 24h.
- lastSeen продлевается, когда хеш встречен в свежем теле; GC — только после
  успешного сетевого обновления.
