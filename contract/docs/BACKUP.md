# BACKUP — семантика LX Backup v1

Нормативно. Схема — `schema/backup.schema.json`. Конверт и процедуры — эволюция
бэкапа LxBox §040 (категории, preview, merge/replace, default-deny allowlist §159);
лаунчер реализует файловый экспорт/импорт впервые (фаза 4).

## 1. Инварианты

1. **Lossless round-trip:** `import(export(x))` в том же приложении = `x`.
   Непереносимое едет в `extensions.<app>` (top-level или внутри сущности);
   принимающая сторона обязана **сохранить чужой блоб нетронутым** до следующего
   экспорта (лаунчер — новое поле state v6; LxBox — новый ключ allowlist).
2. **Default-deny:** неизвестные ключи вне `extensions` — в предупреждение
   пользователю, не в состояние.
3. **Нет молчаливых потерь:** всё, что не применяется, либо в `extensions`,
   либо предъявлено пользователю warning'ом.

## 2. Переносимые сущности

| Секция | Примечания |
|---|---|
| `subscriptions[]` | url, label, tag-политика, update, disabled-отметки, detour. Mobile-only поля подписки (`import_rules`, `identity_override`) — в `extensions.lxbox` записи |
| `servers[]` | ровно одно из `uri` / `config_json`; папки LxBox — в `extensions.lxbox` |
| `rules[]` | `kind: inline\|srs\|preset\|json`; ось порядка `num` — импортёр перенумеровывает, сохраняя относительный порядок; mobile-only матчеры (`packages`, `wifi`) — в `extensions.lxbox` правила |
| `dns` | servers/rules c kind-дискриминатором `template\|preset\|user`, final, strategy |
| `vars` | только portable-имена из `registry/vars.json` |
| `route.final` | символическая ссылка (см. §3) |
| `warp[]` | WG/MASQUE-аккаунты; имена полей — канонические из схемы, маппинг в нативные при импорте |

## 3. Символические ссылки на outbound-цели

`rules[].outbound` и `route.final` переносятся как есть. Если целевой тег
в принимающем приложении не существует (канал `vpn-3` LxBox на десктопе до
SPEC 104; неизвестный preset id вне `registry/presets.json`):

- правило импортируется **выключенным** с warning;
- `route.final` **не применяется** с warning.

После SPEC 104 (каналы в лаунчере) канальные ссылки становятся полноценно
переносимыми; секция каналов переезжает из `extensions.lxbox` в переносимую
(bump схемы до v1.1).

## 4. Disabled-отметки

Перенос **только по identity-хешу** (`IDENTITY.md`); значения — unix seconds,
импортёр конвертирует в свой нативный формат (Go int64 / Dart ISO-8601).
Честные ограничения: отметки нод, патченных mobile import-rules (§302), и нод,
схлопнутых по SNI, на другой стороне не совпадут — истекают по штатному TTL,
пересопоставление в v1 не строится (D-014).

## 5. Секреты

Открытым текстом — by design (граница доверия — локальная машина, как в
state.json / lxbox_settings.json). Шифрование архива — вне scope v1;
предупреждение при экспорте обязательно.

## 6. Версионирование

`lx_backup: 1` — мажор формата. Импортёр отклоняет бо́льшую мажорную версию
с понятной ошибкой («обновите приложение»), меньшую — читает.
