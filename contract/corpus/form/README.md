# Корпус формы узла

> **О чём.** Кейсы «тело узла → что делает с ним форма по реестру» (контракт
> 1.1.122, атрибут `form` поля и секция `body.form`; норма —
> `SPECS/167-F-N-OPENCONNECT_FORM/REGISTRY_DESIGN.md` §3 лаунчера). Обе стороны
> читают один файл и обязаны получить одно и то же: какие поля форма рисует,
> какие требует, какой вариант групп выбора активен, где значение вне
> диапазона формы.

## Файл

Один файл на схему: `<scheme>_form.json`.

```json
{
  "v": 1,
  "scheme": "openconnect",
  "cases": [
    {
      "name": "fortinet_basic",
      "comment": "что проверяет кейс",
      "body": { "server": "…", "flavor": "fortinet" },
      "expect": {
        "visible": ["server", "flavor", "…"],
        "required": ["server", "flavor", "username"],
        "missing": ["username"],
        "choices": { "server_cert_check": "system" },
        "out_of_range": [{ "path": "mtu", "value": 1600 }]
      }
    }
  ]
}
```

- `body` — тело узла в форме ядра (без `type` и `tag`), как его видит форма.
- Пути — от корня тела через точку (`tls.peer_fingerprint`), списки — в
  порядке `order` реестра (обход вглубь: поле, затем его вложенные поля).
- `visible` — поля с атрибутом `form`, которые форма рисует: `visible_when`
  истинно на `body` и ни один предок не скрыт (скрытый объект скрывает всё
  поддерево). Поле без `form` в списки не попадает. `default` поля в условие не
  подставляется: отсутствующий `flavor` не равен `fortinet`, а `not_in`
  на отсутствующем пути истинно.
- `required` — видимые поля с `form.required`, обязательность которых не снята
  `form.required_unless` (задан любой путь из `set`, в том числе неописанный;
  либо в том же объекте не задан сосед из `absent`). «Задан» — ключ есть, не
  `null` и не пустая строка.
- `missing` — поля из `required`, которых в `body` нет: форма не сохранит.
- `choices` — id группы `body.form.choices` → id активного варианта: первый
  вариант, у которого задан хоть один путь из `paths`; если не задан ни один —
  вариант с пустыми `paths`.
- `out_of_range` — видимые заданные числовые поля вне `form.min`/`form.max`.
  Пустое поле границей не судится (ключ не пишется).
- Пустой список и отсутствие ключа равнозначны; сравнение по значению.

Скрытое поле из тела не снимается — форма тело не меняет, корпус проверяет
только вычисление.
