### Возможности (4)

- feat(diagnostics): `logs/crash.log` — трасса фатальной паники дублируется в файл (`runtime/debug.SetCrashOutput`, Go ≥ 1.23; Win7-сборка — заглушка). Windows-бинарь собран без консоли, и паника на старте выглядела как «окно мелькнуло и пропало» без единой строки в логе

- feat(debugapi): `GET /debug/ui` — окна Fyne со стеком overlay-ев и фокусом, `POST /debug/ui/overlays/clear` — снять все overlay-и и разморозить окно без перезапуска; capability `ui`; 504 = заблокирован сам цикл Fyne (`fd88a15e`)

- feat(debugapi): `GET /debug/goroutines` — дамп стеков всех горутин как text/plain (тот же текст, что по SIGQUIT) без остановки процесса; для зависшего UI Fyne, когда stderr ушёл в /dev/null, а lldb-attach убивает процесс. Заголовок `X-Goroutines` — их число; goroutine 1 = цикл Fyne/GLFW (`8ebef696`)

- feat(sources): обфускация AmneziaWG правится у ГОТОВОГО узла — блок в Settings узла-сервера сразу после Detour: домен и браузер маскировки (id/ib) плюс junk-числа jc/jmin/jmax, правки пишутся в тело узла сразу. Виден только когда detour не выбран; назначенный detour снимает поля с узла, а узел, приехавший с обоими сразу, показывает предупреждение вместо блока (`36bb502`, `75908ef`, `890f4e1`, `30bea6b`)

### Исправления (9)

- fix(parser): узел с блоком `tls.reality` получает отпечаток uTLS из chrome-семейства — REALITY-сервер Xray ≥ v26.9.8 требует в ClientHello `key_share X25519MLKEM768`, который несут только chrome-спеки, а прочие отпечатки (и `random` в 4 случаях из 5) сервер молча уводит на камуфляжный сайт: ошибки нет, узел не везёт трафик. Подмена на `chrome` делается на сборке конфига, значение в узле остаётся исходным, на узел вешается код `reality_fp_not_chrome`; пустой отпечаток при reality пишется как `chrome` явно. Заодно битая пара `extra-headers` у naive перестала пропадать молча — код `naive_extra_headers_invalid` (SPEC 083 ядра, контракт 0.12.10, D-102/D-103)

- fix(configurator): «Save As» больше не оставляет без `config.json` — снимок по умолчанию становится текущим состоянием (state.json + пересборка), в диалоге чекбокс «Сделать текущим состоянием и пересобрать конфиг»; без state.json он заблокирован во включённом положении, а снятая галочка даёт прежнее «только снимок». Раньше на первом запуске Save As писал лишь `bin/wizard_states/<id>.json`, визард при следующем открытии был пуст, и каждый старт показывал «Configuration Not Found» (#122)

- fix(gl): гейт OpenGL больше не ставит Mesa3D сам — таймаут пробы (10 с) отделён от отказа драйвера и даёт диалог Retry/Ignore/Abort, установка только по явному «Yes»; перед загрузкой пинится `GALLIUM_DRIVER=llvmpipe` (если переменная пуста), а поставленные DLL проверяются пробой `-gl-probe-local` по полному пути с откатом при неуспехе. Состояние рендерера и факт «дошли до кадра» — в `bin/gl-state.json`, откат на железо — кнопкой в Диагностике и предложением гейта (DLL переименовываются в `.off`); `logs/native-stderr.log` собирает вывод нативного кода, которого у windowsgui-сборки не было вовсе. Смена рендерера теперь применяется самоперезапуском лаунчера (`OPENGL32.dll` стоит в таблице импорта exe и отображается до первой строки Go, поэтому внутри живого процесса рендерер не сменить), а проба железа на время дочернего процесса уводит локальный `opengl32.dll` в сторону — иначе она мерила Mesa и выдавала её за видеокарту (#125)

- fix(shutdown): сторожевой таймер выхода взводится до остановки ядра, а не после — «Quit» из трея выполняется на main-потоке Fyne, и зависшая остановка (macOS: privileged kill ждёт пароль) оставляла процесс без окна и иконки, куда сторож не дотягивался; 15 с на teardown + прежние 3 с на размотку Fyne, диалог ошибки на пути выхода не показывается

- fix(debugapi): `PATCH /state/rules` в режиме `append` (локально и для удалённой машины) не ставил `order_num` новым правилам — при следующей загрузке MarkRuleOrder раздавал им 1000, 1001…, дублируя номера уже существующих пользовательских правил; теперь каждое правило без номера получает `NextUserRuleNum`, а массив сохраняется отсортированным по оси

- fix(fynewidget): индикатор перетаскивания снимал из overlay-ев «верхний, кто бы он ни был» — при чужом overlay поверх обёртка индикатора оставалась навсегда, и окно переставало реагировать на клики при живом процессе (фризы 07–08.09.2026); теперь снимается по ссылке с возвратом лежавшего поверх, плюс очистка на любом DragEnd и Reset (`212b4eac`)

- fix(platform): macOS — нативный пикер файлов резолвит расширения в UTI внутри AppleScript (`UTType typeWithFilenameExtension:`); на macOS 26 голое `of type {"json"}` серило все файлы, и импорт бэкапа/«Add from file» были невозможны; без единого резолва — панель без фильтра (#120)

- fix(backup): импорт бэкапа — после `Import` пересобирается legacy-вид `CustomRules` (`state.RebuildLegacyRuleView`): `LoadState` берёт inline/srs-правила из него, и без пересборки правила из файла считались применёнными, но не доходили до вкладки Rules; `route.final` пишется в `vars["route_final"]` (канонический канал визарда) вместо нечитаемого `config_params["final"]`, экспорт читает его оттуда же — раньше лаунчер `route.final` не экспортировал вовсе (#111)

- fix(wireguard): вставленный .conf с маскировкой больше не теряет её молча — ip/id/ib переносятся из INI наравне с junk-числами; ссылка только с masquerade-сахаром теперь считается AWG-узлом, и её MTU ужимается до потолка AmneziaWG (без этого AWG отказывает молча: рукопожатие проходит, данные не идут) (`f367dd1`)
