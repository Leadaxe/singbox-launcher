2Было → стало: как читается ссылка

Главная перемена релиза. Раньше на каждую схему ссылки — свой рукописный код. Теперь один движок читает таблицы.

Слева — мир до релиза (16 независимых парсеров, 15 эмиттеров). Справа — единый конвейер по таблицам реестра.

3Экосистема: общий контракт с LxBox

Реестр правил (contract/) — общий источник истины для десктопа и телефона.

Разница в версиях контракта — 9 пунктов, аддитивная (LxBox ещё не забрал часть новых правил). Не блокер релиза.

4Страховка: «ядро отвергло узел» (SPEC 132)

Ядро проверяет конфиг целиком и на первом непринятом узле отказывается стартовать вовсе. Страховка находит виновника и отключает его сама.

7Находки независимых ревью

Три ревью прошли перед релизом: страховка SPEC 132, обратный ход (эмит), разбор источников.

Предел попыток демона не срабатывал

Счётчик daemonRejectStartCap обнулялся на каждом повторе — потолок фактически не работал в цепочке «FATAL → выключили → apply → FATAL…». Исправлено dfed276c.

Гонка на кэше движка

Data race на namedValueMaps — check-then-act без блокировки, ловилась go test -race при фоновой пересборке пула узлов. Заменено на sync.Once, исправлено 02691a94, подтверждено race-тестом.

hysteria2, двойной base64 и пять мелочей

При port+mport диапазоны портов терялись — merge: append не исполнялся; двойная base64-обёртка подписки давала ноль узлов. Плюс пять мелочих находок, все 7 подтверждены. Исправлено eb090912.

Три зеркальных дефекта LxBox не воспроизвелись

Три дефекта из ревью LxBox у нас не воспроизвелись — закреплены стражами корпуса. 56ad7444.

Xray-подписки с фрагментацией через freedom

С v1.3.0 подписки с dialerProxy → fragment через freedom теряли серверы. Теперь узел сохраняется и получает tls.fragment. 9e376607, 48b33781.

Форма обфускации AmneziaWG теряла type узла

Найдено ручной обкаткой владельца. Исправлено fe5c0ecb.

Ревью сборки ссылок (эмит)

Дефектов не подтверждено. Полный круговой прогон Copy-link корпуса зелёный, включая AWG/AWG3, xhttp, REALITY, WS early data, Hysteria2, IPv6, Unicode-метки.
