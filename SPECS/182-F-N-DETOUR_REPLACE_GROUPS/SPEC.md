# SPEC 182 — Группы свёртки источников в пикере detour и общий список с цепочкой

Статус: **N** (21.11.2026, реализовано; UI владельцу не показан). Тип: Feature. Контракт не меняется: имя свёртки уже корневая цель ссылок (`NODE_LINK.md`, `allRootLinkTargets` сборки). Парная задача LxBox — 756.

## Проблема

Подписка или папка, свёрнутая в группу («Fold … into a group», `replace {mode, tag, auto}`), не выбиралась целью detour у другого источника: пикер перечислял Направления и верхние узлы, групп свёртки в нём не было. Сборка такую ссылку принимает, переименование свёртки её переписывает (`RenameFoldRefs`), пикер позиций цепочки группы показывал — отставал только пикер detour.

## Решение (решения владельца, 21.11.2026)

1. **Третья ветка «Replace groups»** в дереве пикера detour, между «Directions» и «Nodes».
2. **Все режимы** — manual, auto, both. У both целью идёт селектор `tag`; двойник `<tag>-auto` отдельно не предлагается. Ссылка корневая: `NodeLink{Tag: replace.tag}`.
3. **Не показываются:** группа самого носителя; группа выключенного источника; свёртка с пустым именем; свёртка, чьё имя уже объявлено Направлением, его двойником, тегом шаблона, пресета или свёрткой выше по списку (сборка её не строит — `replace_tag_conflict`).
4. **Кольцо.** Группа, из которой переходы (detour источника, detour его узлов, позиции цепочки) ведут обратно к носителю, показывается с «⚠ leads back here» и не выбирается.
5. **Пикер позиций цепочки — по тем же правилам**, из того же списка: двойник `<tag>-auto` больше не предлагается, группа с кольцом показана с ⚠ и позицией не встаёт.
6. **Один источник списка** — `business.ReplaceGroupTargets(model, holder)`; оба пикера берут группы только из него.
7. **Старые ссылки на двойник** (`<tag>-auto` в detour или позиции цепочки) остаются рабочими: форма их узнаёт и «пропавшими» не помечает.

## Не входит

- Теги свёртки как цели правил и `route.final` — запрет SPEC 108 S3 в силе (`GetAvailableOutbounds` не тронут).
- Защита сборки от кольца через две свёртки, пришедшего из импорта или сырого JSON: здесь кольцо не даёт создать форма.
- Слияние остальных частей двух пикеров (Направления, узлы): наборы целей у detour и цепочки различаются по смыслу.
