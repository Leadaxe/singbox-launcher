## 1. Модель пресета в лаунчере ✅

- [x] Пресет несёт несколько route-правил + DNS-серверы + DNS-правила
- [x] Переменные пресета: `ref` (значение из глобальных), `required` с

      можно

## 3. Ось порядка ✅

- [x] `orderNum` в состоянии, `ui.num` как стартовое значение
- [x] Инварианты D-053: каскад до первой дырки, re-seed несортируемых,

- [x] `NormalizeRuleOrder` при загрузке: старые состояния получают ось без

## 4. Префикс тегов пресета (C7) ✅

- [x] LxBox `namespacePresetTags`: теги DNS-серверов и rule-set'ов пресета →
      `<preset_id>:<tag>`; ссылки изнутри (члены группы, `server`/`rule_set`
      в dns_rules и route-правилах) переписываются вместе с ними
- [x] Найден пробел: `server` у route-правила с `action: resolve` тоже
      ссылается на DNS-сервер пресета — префиксуется
- [x] Heal-редирект `healPresetTagPrefix`: ссылки старых состояний
      переезжают на новые теги; неоднозначные не угадываются
- [x] 8 тестов на heal, ожидания 35 существующих тестов обновлены по смыслу
- [x] `contract/docs/TEMPLATE_LANG.md`: C7 отмечен закрытым
- [x] CHANGELOG LxBox
