# IMPLEMENTATION REPORT 095 — Подзаголовок узла, режимы групп и окно Info

**Дата:** 2026-08-07
**Статус:** Complete.

---

## 1. Что сделано

### Слой чтения config.json

`api.ProxyInfo` из Clash API несёт только тег, тип и задержку — ни транспорта,
ни TLS, ни состава группы. Всё это лежит в сгенерированном `config.json`,
поэтому основой задачи стал не UI, а слой разбора:

| Файл | Назначение |
|---|---|
| `ui/configurator/business/config_nodes.go` | `ConfigNodes` — снимок конфига, `Lookup(tag)` |
| `ui/configurator/business/config_node_labels.go` | `deriveTransport` / `deriveSecurity` — метки для подзаголовка |
| `ui/servers_node_subtitle.go` | сборка подзаголовка, цвет и текст замера |
| `ui/servers_node_info.go` | окно «Info» |
| `ui/configurator/tabs/preview_node_subtitle.go` | то же для вкладки Preview |
| `ui/configurator/tabs/preview_node_info.go` | окно «Info» для превью |

Превью потребовало отдельной пары файлов: узла в `config.json` там ещё нет —
подписка только разобрана и не сохранена, — поэтому данные берутся прямо из
`ParsedNode`.

### Подзаголовок

Под тегом — «протокол·транспорт·security»: `vless·tcp·Reality+Vision`,
`hysteria2·TLS`, `wireguard`.

Протоколы поверх собственного стека (`wireguard`, `masque`, `hysteria2`,
`tuic`) транспорт не приписывают: «wireguard·tcp» было бы неправдой.

### Режимы групп

Тип outbound'а говорит лишь «ядро выбирает само», но не как именно. У `urltest`
есть собственное поле `mode` (SPEC 088):

| Режим | Вид |
|---|---|
| `round_robin` | ⚖️ `[37] по кругу` |
| `least_test` / не задан | 🎯 `[11] быстрейший` |
| `selector` | 🔀 `[39]` — выбор за пользователем |

**Найдено при проверке на боевом конфиге:** первая версия читала только `type`,
и смена режима на `round_robin` никак не отражалась в списке. Исправлено в обоих
местах — список серверов и вкладка Preview.

### Замер вместо кнопки Ping

Кнопка заменена на кликабельное цветное значение: зелёный до 150 мс, жёлтый до
300, оранжевый выше, красный при ошибке; «Ping», пока замера не было.

Причина замены: `widget.Button` в Fyne не позволяет покрасить свой текст — есть
только `Importance`, а он заливает весь фон, и число тонет в заливке. Клик
обрабатывает `fynewidget.TapWrap` (он же ставит курсор-указатель).

### Окно Info

Правый клик по узлу — в списке серверов или на вкладке Preview. Две вкладки:
разобранные поля и точный outbound-JSON.

Показывается: сервер, транспорт с параметрами, TLS/REALITY (SNI, ALPN,
fingerprint, public_key, short_id), цепочка detour, состав группы с
подзаголовком каждого члена и параметры отбора — `mode`, `tolerance`,
`idle_timeout`, `pool`, `pool_tolerance`, `sticky_hash`, `sticky_ttl`.

**Найдено при проверке:** первая версия показывала у группы только `url` и
`interval`, и всё, что относится к round_robin, оставалось невидимым.

### Выключение отдельных узлов (перенос из SPEC 094 D4)

Чекбокс у каждого узла на вкладке Preview источника. Отметка хранится в
`ProxySource.DisabledNodes` по хешу идентичности, поэтому переживает обновление
подписки, перезапуск и переименование узла провайдером. GC по TTL
`clamp(3 × интервал, 24h, 30d)` — только после успешного сетевого обновления.

Узел без вычислимого хеша показывается включённым и заблокированным: отметку не
к чему привязать, и она переехала бы на соседа.

## 2. Ошибки, найденные при проверке

**Гонка в GUI-потоке.** `UpdateTemplatePreviewAsync` трогал виджеты Fyne
напрямую, работая внутри фоновой горутины. Fyne помечал это как «Error in Fyne
call thread»; проявлялось вылетом приложения на последнем шаге сохранения
визарда. Исправлено — три места обёрнуты в `SafeFyneDo`
(`ui/configurator/presentation/presenter_async.go`). Проверено детектором гонок.

При этой правке чуть не внесена регрессия: превью для конфигов больше 50 КБ
перестало бы показываться вовсе. Замечено, исправлено — текст ставится в обеих
ветках, разница только в статусе.

**Верстка строки.** Подзаголовок как `widget.Label` наезжал на имя: у Label
собственные вертикальные отступы под полный размер шрифта темы. Заменён на
`canvas.Text` с явным размером. Место под подзаголовок резервируется всегда —
`widget.List` берёт высоту строки из первого созданного элемента, и скрытый
элемент дал бы строки разной высоты.

**Битый глиф.** `→` (U+2192) в списке DNS-правил рисовался «плиткой» U+FFFD: в
основном шрифте темы Fyne этого глифа нет. Заменён на эмодзи — они идут
отдельным шрифтом и отображаются всегда.
