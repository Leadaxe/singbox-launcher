# SPEC 113-E — UI: потоки, scope, отзывчивость

Закрывает находки аудита: M4 (I/O на UI-потоке в селекторах), M5 (Local
получает группы роутера), M6 (interface-пикер морозит Settings) + миноры
UI-зоны.

## M4. updateSelectorList: сбор данных — с UI-потока в фон

ui/clash_api_tab.go:330–352. Фикс v1.5.3 завернул в fyne.Do мутации
виджетов, но сбор данных (чтение config.json, gRPC RemoteDaemonGroups)
остался в потоке вызова — а из пяти путей вызова четыре идут ИЗ UI-потока
(onResetAPIState через UpdateUI/fyne.Do — core/uiservice/ui_service.go:245;
колбэки :466/:507; клики :1645/:1677). Stop при недоступном роутере
блокирует главный цикл на весь dial-дедлайн — класс «зависший Stop» не добит.

Фикс: инвертировать схему — публичная updateSelectorList запускает горутину
(или сериализованный воркер), которая собирает данные, затем fyne.Do на
мутации. Повторные вызовы во время сбора схлопывать (генерация/coalescing —
паттерн уже есть в панели). Ни один путь вызова не должен делать сеть/диск
на UI-потоке. Проверить и pulse-обработчики.

## M5. Группы: резолвер обязан брать scope

ui/clash_api_tab.go:340 проверяет RemoteDaemonGroups() ДО scope — при
подключённой удалённой машине Local-панель получает группы роутера. Новый
подписчик ConfigBuilt (ui/app.go:225–235) сделал ветку достижимой для
локальных пересборок. Это повтор задокументированного класса
«remote-override глобальный» (память проекта).

Фикс: гейт `scope == services.ScopeRemote` перед обращением к
RemoteDaemonGroups; у Local-панели источник групп — только локальный
config.json. Тест: подключён remote + ConfigBuilt(local) → Local-панель
читает локальные группы (падает на старом коде).

## M6. Interface-пикер: без синхронного REST на UI-потоке

ui/configurator/tabs/settings_tab.go:637–660 + settings_interface_pick.go:81:
построение строки «interface» при remote-таргете синхронно зовёт
HostInterfaces() (REST + mTLS, таймаут 30 с) — на КАЖДЫЙ refresh вкладки
Settings. Машина «подключена», но не отвечает → приложение висит.

Фикс: ряд строится сразу из кэша (пустой список = плейсхолдер «загрузка…» /
последний известный), запрос уходит в горутину с коротким таймаутом и
кэшем per-machine; ответ доезжает через fyne.Do. Повторные refresh не
плодят параллельные запросы (single-flight). То же правило для локального
пути: core/netiface/friendly_darwin.go:26 запускает networksetup — первый
вызов тоже увести с UI-потока (прогрев в горутине при открытии вкладки).

## Миноры зоны (обязательные)

1. ui/core_dashboard_tab_status.go:98–113 — вернуть безусловный
   `if tab.controller == nil { return }` ДО счётчика тиков (сейчас 8-й тик
   уронит на nil). Комментарий «watcher тикает ~раз в секунду» не
   соответствует коду (периодического вызова нет) — переписать честно:
   счётчик движется на попутных refresh.
2. ui/configurator/business/detour_refs.go:47–61 — tagIsUnique считается
   ПОСЛЕ записи переименования в модель: тёзка в другом источнике теряет
   свои tag-only ссылки. Считать уникальность до перезаписи (или исключать
   переименованный источник из подсчёта).
3. ui/configurator/tabs/source_edit_window.go:612–620 — OnChanged пишет
   node_tag прямо в модель, Cancel не откатывает, сброс ссылок с диалогом
   делается только на Save. Фикс: буферизовать до Save (как остальные поля
   формы) либо откатывать на Cancel; сброс ссылок обязан идти любым путём,
   каким тег реально меняется.
4. ui/servers_node_info_chain.go:186–212 — при двойном сбое (Set + перечитка)
   чекбокс позиции цепочки остаётся в положении, которое ядро отвергло:
   явно возвращать пред-кликовое значение при !ok.
5. core/netiface/interfaces.go:106 — FlagPointToPoint отсекает
   PPPoE/mobile-WAN аплинки из List(), а диагностика bind_interface врёт
   «has no IP address». Не фильтровать PtP при наличии адреса; текст
   диагностики — по фактам.
6. bin/locale/ru.json — убрать дубль ключа "off" (строки ~2428/~2539,
   значения идентичны; после правки json валиден, ключ один).

## Запреты

- fyne.Do — единственный способ трогать виджеты из фона; DoAndWait — только
  для коротких снапшотов состояния UI-потока, не для сети.
- Никаких новых Test* на форматирование строк/вёрстку (память проекта).
- ui/machine_* (heartbeat/wire-log, только что принято, коммит 2ca3ccd) —
  не трогать, кроме случаев, когда фикс этого SPEC его прямо требует.
