# SPEC 175 — Taildrop: отправка и приём файлов на десктопе

Решение владельца 02.11.2026 (через сессию LxBox): лаунчер у себя отправляет и
принимает файлы Taildrop. Опора — фича LxBox `032-TAILDROP` и задача LxBox 707.
Буфер обмена (контракт 1.1.146, `docs/CLIPBOARD.md`) — отдельной задачей после
этой.

## 1. Где работает

Taildrop идёт через gRPC `StartedService` ядра (`SubscribeTaildropInbox`,
`SendTaildropFiles`, `DownloadTaildropFile`, `DeleteTaildropFile`,
`CancelTaildropReceiving`). Значит — там же, где у лаунчера уже есть команды
tailnet (SPEC 148): локальный демон (macOS, Windows amd64/arm64) и удалённые
машины lxd. Linux classic и Windows 386 ходят в Clash API — Taildrop там нет,
вкладка Network там не показывается и сейчас.

Ядро: десктопные LX_TAGS без `ts_omit_*`, Taildrop есть с `1.14.0-lx.27`.
Пересборка ядра не нужна.

## 2. Каталог входящих

`taildrop_directory = <state_directory>/taildrop`. Подставляется при сборке,
только если ключа нет в теле узла; хранимое тело не трогаем. Без этого все
узлы tailscale делят каталог ядра по умолчанию (`<base>/Taildrop`).
Каталог живёт внутри каталога состояния узла и вместе с ним переименовывается,
удаляется и переносится демоном в его runtime-каталог (macOS).

## 3. Вкладка Network окна узла

### 3.1 Files (входящие)

Секция `Files` после `This device`:
- у узла `canShareFiles == false` — строка «File sharing is off for this
  tailnet. Turn on Taildrop in the Tailscale admin console.»;
- принимаемые: имя, `получено / размер`, кнопка Cancel;
- принятые: имя, размер, отправитель; кнопки Save и Delete;
- пусто — «No files.».

Save: файл сохраняется в `~/Downloads` (при совпадении имени — `name (2).ext`)
и убирается из входящих. Ошибка — диалогом, файл остаётся во входящих.
Delete — с подтверждением.

Входящие — подписка `SubscribeTaildropInbox` на время открытого окна.

### 3.2 Send file…

Пункт «Send file…» в меню `…` устройства, если: узел умеет делиться
(`canShareFiles`), устройство в сети, `canReceiveFiles`, не расшаренное
(`!shareeNode`). Выбор файла — диалогом; отправка — лист с прогрессом и Cancel.
Ядро не работает или источника команд нет — пункта нет (очереди нет).

### 3.4 Автосохранение

Галка «Save to Downloads automatically» в секции Files (решение владельца
02.11.2026). Включена — лаунчер держит подписку на входящие узла всё время,
пока ядро его машины работает (не только при открытом окне), и каждый принятый
файл сохраняет в `~/Downloads` тем же путём, что Save, и убирает из входящих.
На macOS после сохранения — системное уведомление. Галка — настройка этого
компьютера (`settings.json`, `taildrop_auto_save`: машина + тег), в бэкап не
идёт; для удалённой машины файлы ложатся в Downloads этого компьютера.
Направить `taildrop_directory` прямо в Downloads нельзя: ядро считает весь
каталог своими входящими (Delete удалял бы файлы пользователя), а демон macOS
пишет от root.

### 3.5 Allow Taildrop

Галка узла «Allow Taildrop (send and receive files)» — в Add server → Tailscale
и в блоке Tailscale окна правки узла. По умолчанию ВЫКЛЮЧЕНА (решение
владельца 02.11.2026, контракт 1.1.150): вкл пишет в тело
`disable_taildrop: false`, выкл снимает поле; сборка эмитит
`disable_taildrop: true` при отсутствии поля (`applyTailscaleTaildropDefault`).
Поле с `min_core 1.14.4-lx.30-rc.2`: на ядре старше гейт его снимает, Taildrop
там как у ядра. Выключено в собранном конфиге — секция Files пишет «Taildrop
is off for this node…», «Send file…» нет. Полевой гейт сравнивает пре-релизы
(`lx.30-rc.1 < lx.30-rc.2 < lx.30`).

### 3.3 Журнал

Имена файлов и устройств в журнал не пишутся (как SPEC 148 §3): только тег
узла и число байт.

## 4. Не входит

- Уведомления о приёме без автосохранения (у демона нет платформенных
  уведомлений; на Windows лаунчер их не умеет).
- Drag-and-drop на устройство, отправка нескольких файлов одним листом,
  «Save as…».
- Буфер обмена — следующая задача (контракт 1.1.146).

## 5. Контракт

Текст `registry/protocols/tailscale.json` (`note` эмиттера: подставляется ещё и
`taildrop_directory`) → 1.1.147, TASKS_LXBOX §143. Поведение сборки у LxBox
такое же (задача 707).
