Пять самостоятельных заданий, которые надо закрыть перед следующим релизом.
Каждый файл написан так, чтобы его можно было отдать человеку, впервые
открывшему репозиторий: цель, границы, готовая разведка со ссылками
`файл:строка`, ловушки, шаги, проверка, коммит, формат отчёта.

Это **папка-контейнер с ТЗ**, а не обычная задача Spec Kit: здесь нет
общих `SPEC.md` / `PLAN.md` / `TASKS.md`, их роль играют сами `TASK_*.md`.

## Порядок и зависимости

**Независимы полностью** (можно вести параллельно разными людьми, файлы не
пересекаются): **2**, **4**, **5**.

**Требуют координации:**

- **Задача 3** трогает `contract/registry/warnings.json`. Этот каталог
  сейчас в работе у другого исполнителя (движок разбора ссылок). **Не
  начинать, пока владелец не подтвердит, что реестр свободен** — иначе
  бамп `contract/VERSION` разъедется с чужим.
- **Задача 1** — самая крупная, четыре независимых хвоста внутри. Хвосты
  1.1 (петля на Final) и 1.3 (удалённые машины) связаны: 1.3 переиспользует
  адаптер черновика из 1.1, поэтому 1.1 делается первой. Хвосты 1.2
  (сигнал демона) и 1.4 (зазор бэкапа) не зависят ни от чего.
- **Задачи 2 и 4** обе смотрят на последствия SPEC 133, но правят разное:
  2 — только `.md`, 4 — только `.go`. Конфликта файлов нет.

**Рекомендуемая последовательность, если исполнитель один:** 5 → 4 → 2 → 1 → 3.
Сначала дешёвое и изолированное, крупное — в конец, реестр — последним и
только после отмашки владельца.

## Общие правила для всех пяти

Одинаковы во всех ТЗ, продублированы в каждом файле — читать всё равно
только свой:

- ветка **только `develop`**, `git checkout` / `switch` / `stash` / `reset` /
  `rebase` / `clean` / `git add -A` / `git commit -a` **запрещены**;
- рабочая копия **разделяемая**: коммитить только свои файлы явным списком
  путей (`git commit -m "…" -- path1 path2`), чужие незакоммиченные правки
  не трогать;
- локально — только `go build ./...` и **свой именованный** тест
  (`go test ./пакет/... -run 'ИмяТеста' -count=1`). Полный прогон, `go vet`
  по репозиторию и Win7-сборка — **только CI**;
- на машине живой VPN: **никогда** не запускать `sing-box run`, не убивать
  процессы sing-box (`pkill`/`killall`), не трогать бинарь ядра в бандле;
- ни `sudo`, ни ввода паролей, ни тегов, ни merge/PR в `main`, ни смены
  версии приложения;
- Win7-сборка идёт тулчейном go1.20: в общем коде без builtin `min`/`max`,
  без пакетов `slices`/`maps`, без `http.Request.PathValue`,
  без `range` по целому числу;
- новые ключи `locale.T` — сразу с переводом в `bin/locale/ru.json`;
- секреты в `state.json` лежат открыто **намеренно** — не маскировать и не
  репортить как утечку;
- в коммитах, коде и документах не упоминать AI-агентов и модели.
