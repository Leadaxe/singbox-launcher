## Отклонения от плана

1. **Инкрементальный переход вместо одного коммита** (зафиксировано в PLAN до
   реализации): движок параллельно старому, оба стиля ключей работали до
   финального strip; каждый коммит — рабочий.
2. **Вынос в const — скриптом**, не субагентами: детерминированная
   трансформация, имя из старого ключа. 1 сайт (`internal/dialogs/dialogs.go`)
   отложен — файл был в работе у параллельной сессии.
3. **Ratchet не рекурсирует в ветки** — в Go нет тернарного оператора; поток
   переменных не отслеживается (осознанный best-effort зазор, README).
4. **Русские WarnLog-строки** в `outbound_generator`/`detour_group_cycle`/
   `direction_twins` оставлены: логи не переводятся, чистка языка логов —
   отдельная задача.
5. Попутно: агент-вычитка нашла и закрыла нелокализованный `ui/traffic`
   (28 строк) и «сырой ключ» GitHub-rate-limit в `core_dashboard_tab.go`.
