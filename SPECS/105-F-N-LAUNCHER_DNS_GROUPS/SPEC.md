# SPEC 105 — DNS-группы в лаунчере (как в LxBox)

Часть программы SPEC 103 (цель 8 пользователя). Выполняется после SPEC 104 —
использует ту же модель ссылок.

## Проблема

DNS-настройки лаунчера — v6 `dns_options` (servers/rules с kind
`template|preset|user`); в LxBox поверх этого есть DNS-группы (§312/§354 —
группировка DNS-серверов с выбором через ядро, `ccGetDnsGroups`), которых
в лаунчере нет. Для «общей логики» (цель 6) и переносимых бэкапов DNS-секция
должна вести себя одинаково.

## Цель

Портировать DNS-группы LxBox в лаунчер; выровнять форму `dns_options` обоих
проектов под обменную схему SPEC 103 (PLAN §9.D7: kind-дискриминатор — модель
лаунчера, группы — модель LxBox; берём лучшее из обеих, вердикт в DECISIONS.md).

## Рамки

- Эталон: LxBox §312/§354 (`dns_ref.dart`, DNS-группы в билдере и UI),
  плюс lx-расширения ядра (`ccGetDnsGroups` / `CommandDNS`).
- Перед портом — архитектурное ревью обеих реализаций (цели 9–10).
- Не ломать существующие v6 dns_options; миграция с сохранением поведения.

## Статус

Черновик-скелет. Детальный PLAN/TASKS — после SPEC 104.
