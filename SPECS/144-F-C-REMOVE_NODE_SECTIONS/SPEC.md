# SPEC 144 — Секции узла упразднены

Статус: **C** (решение владельца 2026-09-27, реализовано 2026-09-27).
Коммиты: `c68703e0` (контракт 1.1.85, снятие секций).
Тип: Feature (снятие). Контракт: бамп `contract/VERSION` → **1.1.85**, параграф **§82** в `contract/TASKS_LXBOX.md`.

Источник решения — спека LxBox §575
(`LxBox/docs/spec/tasks/575-remove-node-sections.md`). Здесь — только то, что
касается лаунчера. Норма обеих сторон — `contract/docs/NODE_SECTIONS.md`.

---

## 1. Проблема

Поле `sections` (SPEC 121/122) давало узлу власть над всем конфигом: его
правила вставали на общую ось, его DNS-записи дописывались в общие списки,
тело правила было сырым. Вставив чужой узел документом, пользователь получал
изменённые маршруты и DNS всего приложения.

## 2. Решение

| Запись | `sections` |
|---|---|
| свободный узел (корень и папка), любой протокол, включая Tailscale | нет |
| папка | нет |
| подписка | имя зарезервировано, не читается и не пишется |
| узел подписки, цепочка, группа, Направление | нет |

- Состояние: ключ `sections` у узла не читается (поле модели удалено) и
  пропадает при первом сохранении; миграция v7→v8 ключ снимает. Версия
  формы не меняется.
- Разбор: из целого sing-box-конфига и из документа узла берутся только узлы;
  `dns`/`route`/`sections` документа отбрасываются, окно источника и форма
  «Add server» говорят об этом пользователю. Каноническая связка Tailscale
  не подставляется; код `tailscale_from_subscription` выведен.
- Сборка: инъекция секций и подстановка `@self` удалены.
- Бэкап: экспорт `sections` не пишет; импорт снимает поле у записи любого
  вида, непустое — с `backup_section_record_dropped` (`reason: not_allowed`).
- UI: строки правил узла на вкладке Rules, строки DNS узла на вкладке DNS,
  окно просмотра правила узла удалены.

## 3. Вне задачи

Связку tailnet (MagicDNS, маршрут) даст пресет шаблона — задача LxBox §578,
отдельная версия контракта. До неё узел Tailscale собирается без маршрута в
tailnet и без MagicDNS.

## 4. Реализация

- `core/state`: удалены `node_sections_convert.go`, `selfvar.go`,
  `tailscale_bundle.go`; `node_sections.go` → `record_clone.go` (только
  копии записей); `Node.Sections` удалено.
- `core/config`: `node_document.go` — только тело + список отброшенных
  ключей; `subscription/singbox_sections_extract.go` удалён.
- `core/build`: `NodeSectionSet`, инъекция в `preset_merge.go` удалены.
- `core/backup`: `node_sections.go` — снятие поля по сырому файлу
  (`scanSections10`) для 1.0 и по блоку 0.12.
- `ui/configurator`: `models/node_rule_ref.go`, `business/node_sections.go`,
  `tabs/node_rule_view_window.go` удалены.
- Тест волны: `core/backup/sections_dropped_test.go`.
