# Решения по итогам разведки (recon/*.md)

Капитанские решения по конфликтам кода с DRAFT. Принцип мандата: Саша дал
полное право на оркестрацию; решения, меняющие ранее согласованное с ним,
помечены `[REVIEW]` — показать при ревью. Остальное — доопределение модели
в её же духе.

## Идентичность и теги (fetchpipe-К2, groups-К2 — САМОЕ ВАЖНОЕ)

**`Node.tag` = СЫРОЙ тег (идентичность в рамках контейнера), снятый до
тег-политики.** Финальный конфиг-тег = `tagPolicy(prefix + tag + postfix)`
вычисляется на эмиссии; у верхних узлов политика отсутствует → финальный
тег = tag. Это прямое продолжение SPEC 112: merge-ключ, enable, detour,
NodeLink живут на сыром теге и переживают правку политики. Формулировка
DRAFT «tag — он же тег в конфиге» верна только для верхних узлов.

- NodeLink{folderId, tag}: tag — сырой тег узла в папке; при folderId=null —
  финальный тег корневого пространства.
- Дубли тегов в одном теле подписки: fetch-уникализация (X, X-2) остаётся
  ДО merge; merge-ключ = уникализированный сырой тег.
- `dedupSignature` (дедуп по содержимому, регресс v1.5.2) остаётся
  fetch-стадией — merge-по-тегу его НЕ заменяет.
- Переменные `{$num}`/`{$server}`/… в prefix/postfix сохраняются (умирает
  только mask).
- Уникализация финальных тегов между источниками — на эмиссии
  (MakeTagUnique), как сегодня.

## Detour (groups-К1, warp-К5)

**`detour` объявляется ТОЛЬКО у Server, НЕ у Node.** У Chain detour
избыточен по построению (поправка Саши): маршрут целиком в hops,
«через X» = вставить X ближним хопом; проекция chain-источника detour
и сегодня не проносит. У Auto и FolderReplace detour не существует:
selector/urltest не принимают dial-поля — сегодняшний штамп
source-detour на группы это латентный баг, модель его закрывает типом.
Папочный общий detour применяется к Server-узлам без личного и
ПРОПУСКАЕТ Chain и Auto. Body чист от detour: ApplySourceDetour-запекание умирает, вся
маршрутизация — NodeLink на эмиссии.

Исключение ядра сохраняется как есть: detour не применяется к
WireGuard-узлам (комментарий connections.go:146 становится правилом модели).

## Auto (groups-К3..К7, strategy)

- Поля Auto: `groupType (selector|urltest)`, `default?` (для selector),
  `members []NodeLink`, `strategy AutoStrategy`.
- **AutoStrategy = сегодняшний `configtypes.DirectionAuto`** (9 полей:
  mode/url/interval/idle_timeout/tolerance-TemplateInt/interrupt-трёхзначный/
  pool/pool_tolerance/sticky_hash) — не изобретаем, переносим. idle_timeout
  остаётся полем (сирота в UI — допустимо).
- Битый/выключенный член = prune с warning (сегодняшняя семантика
  member-ребра); detour остаётся fail-closed. Auto, потерявший всех членов,
  не эмитится + warning.
- Эмиссия Auto сама фильтрует выключенных членов (при материализации
  node.enabled больше не удаляет узел физически).
- Вложенные группы (Auto-член Auto) — ЗАПРЕЩЕНЫ в v1; парсер, встретив,
  теряет с warning (сегодня теряет молча).
- Origin у Auto допустим (kind=json), Regen для Auto ОТКЛЮЧЁН (группа
  непересобираема из фрагмента — состав контекстный).
- collapsedInto (перепривязка члена-дубля на выжившего) переезжает в
  fetch-резолв членов.

## FolderReplace (strategy-К3..К7)

- Гард занятости тегов ЕДИНЫЙ на сборку: направления + твины + replace +
  «-auto»-двойники + верхние узлы (сегодня гард видит только направления —
  deps-К12).
- Пул кандидатов Направлений (замена WIZARD-маркеров и
  ExposeGroupTagsToGlobal): верхние узлы + узлы папок без replace +
  replace-теги папок с replace. Это правило пула, механизм маркеров умирает.
- Replace-авто исключает Auto-узлы своей папки из состава (перенос правила
  dropGroupNodes).
- Селекторная половина: default = авто-двойник при both,
  interrupt_exist_connections — из шаблонных опций (как сегодня); отдельных
  полей не заводим.
- Миграция fold→replace обязана МАТЕРИАЛИЗОВАТЬ вычисленный тег (включая
  позиционный дериватив «N:auto» при пустом префиксе) в replace.tag.

## WARP (warp-К1..К4)

- `OriginKind` БЕЗ warp: WARP-узел = Server{origin{kind:uri, raw:URI}} —
  сегодняшняя правда, kind=warp носителя не имеет.
- Тег при добавлении узла уникализируется в контейнере (лечит константный
  DisplayTag «WARP (MASQUE)» при H2+H3 из одной регистрации).
- `warp_accounts` — независимая корневая секция, живёт отдельно от узлов;
  удаление узла кеш НЕ трогает (мотив: не плодить CF-device). Зафиксировать
  в state.md, чтобы рефакторинг не счёл сиротой.
- Однослотность при импорте бэкапа (перезапись слота приёмника) — известная
  цена, наследуется.

## Подписка и fetch (fetchpipe)

- `skip[]` — поле Subscription, применяется на fetch ДО merge. Правка skip
  действует со следующего обновления; отсечённый узел выпадает как
  «исчезнувший» (в подписке = удаляется). `[REVIEW]` — Саша skip не обсуждал.
- `max_nodes` СТАНОВИТСЯ реальным капом парса при fetch (сегодня — только
  бейдж; константа 3000 остаётся аварийным потолком). Резолв: подписка →
  настройки приложения (двухступенчатый — заголовка провайдера нет).
- Truncated-достоверность: обрезанный parse достоверен В ПРЕДЕЛАХ капа —
  merge обновляет совпавших и добавляет новых, но УДАЛЕНИЕ «исчезнувших»
  запрещено (не отличить «исчез» от «за капом»).
- Fetch-диагностики (lastError, announce, статусы) персистятся в
  Subscription.updateStatus — отчёт сборки и UI читают state, а не
  перепарсивают. SubMeta остаётся (userinfo, announce, даты).

## Миграция v6→v7 (deps, fetchpipe, tests)

- Выполняется, пока raw-кэш ЖИВ: материализация nodes[] из кэша →
  применение disabled_nodes (включая legacy-64hex; несматченные — warning) →
  снос кэша и карты. Кэша нет → nodes[] пуст, карта отбрасывается с warning.
- `TagMask` server/chain-источников — это ХРАНИЛИЩЕ тега узла: миграция
  переносит NodeTagOrLabel → Node.tag (mask умирает только как фича
  подписки).
- `Chain.Hops []string` → `[]NodeLink`: резолв через живой индекс узлов на
  миграции; нерезолвящийся хоп → NodeLink{null, старый-тег} (fail-closed на
  сборке) + warning.
- `DetourNodeSourceID` на бывший server-источник → NodeLink{null, tag};
  коллизии верхних тегов валидируются на миграции (уникализация + перепись
  ссылок + warning).
- Standalone `exclude_from_global` (без fold) теряется с warning + записью
  в отчёт миграции. `[REVIEW]` — Саша принимал смерть флага в контексте
  свёртки.
- Локальные Направления: fold-производные → replace; произвольные —
  теряются с warning (решено Сашей).
- Golden real-v088: прогнать миграцию, перезафиксировать снимок.
