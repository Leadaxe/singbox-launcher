# Отбор узлов для Направления

**Направление** — именованная цель, на которую ссылаются правила. Какие узлы в
него попадут, решает одно поле — **отбор узлов**.

Отбор — регулярное выражение по **итоговому тегу** узла, ровно по тому тексту,
который виден в списке узлов, уже с префиксом подписки. Оставьте поле пустым —
и Направление возьмёт все узлы.

## Что вводить

Только **тело** выражения. Без косых черт и флагов:

| Нужно | Вводим |
|---|---|
| Немецкие узлы с тегом `🇩🇪 Frankfurt` | `🇩🇪` |
| Германия **или** Нидерланды | `🇩🇪\|🇳🇱` |
| Теги, начинающиеся с `DE-` | `^DE-` |
| Теги, кончающиеся на `-premium` | `-premium$` |
| Всё, **кроме** России | `🇷🇺` + галка **Инверсия** |

**Регистр не учитывается никогда.** `de-` совпадёт с `DE-Frankfurt`. Это не
настройка: теги подписок приходят в произвольном регистре, и учёт регистра
ломался бы при первом же переименовании у провайдера.

**Эмодзи работают.** Флаг страны — самое устойчивое, что есть в теге подписки:
города переименовывают, флаги — почти никогда.

## Что понадобится на практике

| Знак | Значение | Пример |
|---|---|---|
| обычный текст | содержит этот текст | `Frankfurt` |
| `\|` | одно или другое | `🇩🇪\|🇳🇱\|🇧🇪` |
| `^` | начало тега | `^AL:` |
| `$` | конец тега | `2$` |
| `.` | любой один символ | `DE-.` |
| `.*` | любой текст, в том числе пустой | `DE.*prem` |
| `[abc]` | один из символов | `[0-9]` |
| `\.` | точка как символ | `example\.com` |

Остальное — [синтаксис RE2](https://github.com/google/re2/wiki/Syntax); из
заметного не поддерживаются ретроспективные проверки и обратные ссылки.

## Инверсия

Галка **Инверсия** оставляет узлы, которые **не** совпали. Это честный способ
сказать «всё, кроме»: выражение, исключающее что-то, — головоломка, а галка —
нет.

При пустом отборе инверсия не значит ничего: «всё, кроме ничего» — это всё.

## Узел по умолчанию

**Узел по умолчанию** — второе регулярное выражение, читается так же. Первый
совпавший узел становится начальным выбором Направления. Пусто — ядро возьмёт
первый узел списка.

Если у Направления включён автовыбор, умолчанием становится его группа
`<tag>-auto` — но только если это поле ничего не поймало: явный выбор
пользователя важнее.

## Когда не совпало ничего

Отбор, не поймавший ни одного узла, оставляет Направление пустым, а пустое
Направление **блокирует** трафик своих правил (переключиться на прямое
соединение можно вручную). Так задумано: молча выпустить этот трафик мимо VPN
было бы хуже. Лаунчер предупреждает об этом и называет Направление.

**Некорректное** выражение — незакрытая скобка, лишняя `(` — игнорируется
целиком, как будто поле пустое: опечатка не должна стоить вам всех узлов.
