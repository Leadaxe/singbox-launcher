# Release notes — v2.3.10 (2026-10-14)

## EN

A patch release after v2.3.9. Core `sing-box-lx 1.14.3-lx.18` unchanged, contract 1.1.119 unchanged.

### New
- **Tailscale node → Network: the device list looks like the server list.** Compact rows: the name and IPv4 on top, OS and roles with IPv6 below, and how the device is reached on the third line — a green bolt for `direct <address:port>`, an orange cloud for `relay <region>` / `peer relay`, `no traffic yet` for an online device nothing has talked to yet (Tailscale opens the tunnel on the first packet), `last seen … ago` for an offline one. Hovering that line explains what the path means. A device with more than two addresses gets a `+N` expander, and **Copy address** in the ⋯ menu offers every address. Diagnostics → Tailnet shows devices with the same row.
- **The Network tab is live.** While it is open it asks the core for the current status every 3 s (`GetTailscaleStatus`, as Diagnostics does), so the path is what the core sees now instead of the last streamed snapshot, which could stay empty or stale until the next tailnet event. With a core that has no such request the tab falls back to the stream, as before.
- **macOS install script:** refuses to run on anything but macOS before touching the network, instead of failing later on a missing tool.

## RU

Патч-релиз после v2.3.9. Ядро `sing-box-lx 1.14.3-lx.18` и контракт 1.1.119 без изменений.

### Новое
- **Узел Tailscale → Network: список устройств как список серверов.** Компактные строки: имя и IPv4 сверху, ОС и роли с IPv6 ниже, третьей строкой — как достижимо устройство: зелёная молния у `direct <адрес:порт>`, оранжевое облако у `relay <регион>` / `peer relay`, `no traffic yet` у устройства в сети, с которым ещё не было обмена (Tailscale поднимает туннель по первому пакету), `last seen … ago` у устройства не в сети. Подсказка при наведении на эту строку объясняет, что значит путь. У устройства с адресами сверх двух — раскрытие `+N`, а **Copy address** в меню ⋯ предлагает каждый адрес. Diagnostics → Tailnet показывает устройства той же строкой.
- **Вкладка Network живая.** Пока она открыта, раз в 3 с спрашивает у ядра текущий статус (`GetTailscaleStatus`, как Diagnostics), так что путь — тот, что ядро видит сейчас, а не последний снимок потока, который мог оставаться пустым или устаревшим до следующего события tailnet. С ядром без такого запроса вкладка берёт данные из потока, как раньше.
- **Скрипт установки на macOS:** отказывается работать не на macOS ещё до обращения к сети, а не падает позже на отсутствующей утилите.
