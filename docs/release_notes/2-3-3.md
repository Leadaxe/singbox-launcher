# Release notes — v2.3.3 (2026-09-28)

## EN

Hotfix on top of v2.3.2. Core `sing-box-lx 1.14.2-lx.4`, contract 1.1.84 — unchanged.

### Fixed
- **Windows, launcher run as administrator: a failed permission check no longer leaves you without VPN** ([#137](https://github.com/Leadaxe/singbox-launcher/issues/137)). The core refused to start with “core log …\sing-box-lxd\logs\classic.log: C:\ProgramData: … is granted 0xd0040, must not be writable by a non-administrative account” when the system folder `C:\ProgramData` gave write access to everyone. For the core log the launcher now checks only `C:\ProgramData\sing-box-lxd` and its `logs` folder, the same way the core does.
- **Permission checks of the elevated start warn instead of blocking.** When the protected core copy or the log folder fails a check, the dialog names the rights in words, explains the risk, shows a command that fixes it (an `icacls` command when the problem is in a folder above ours) and offers **Run anyway**. Until the launcher is closed, Run anyway starts the launcher's own core and/or writes the core output to the launcher's own log. See [SPEC 150](../../SPECS/150-B-C-WINDOWS_PRIVILEGED_GATE_WARNING/SPEC.md).

## RU

Хотфикс поверх v2.3.2. Ядро `sing-box-lx 1.14.2-lx.4`, контракт 1.1.84 — без изменений.

### Исправлено
- **Windows, лаунчер с правами администратора: неудачная проверка прав больше не оставляет без VPN** ([#137](https://github.com/Leadaxe/singbox-launcher/issues/137)). Ядро не стартовало с ошибкой «core log …\sing-box-lxd\logs\classic.log: C:\ProgramData: … is granted 0xd0040, must not be writable by a non-administrative account», если системная папка `C:\ProgramData` давала всем право записи. Для лога ядра лаунчер теперь проверяет только `C:\ProgramData\sing-box-lxd` и его папку `logs`, так же как ядро.
- **Проверки прав повышенного старта предупреждают, а не запрещают.** Если защищённая копия ядра или папка лога не прошли проверку, диалог называет права словами, объясняет риск, показывает команду исправления (`icacls`, когда проблема в папке выше нашей) и даёт кнопку **Run anyway**. До закрытия лаунчера Run anyway запускает собственное ядро лаунчера и (или) пишет вывод ядра в собственный лог лаунчера. См. [SPEC 150](../../SPECS/150-B-C-WINDOWS_PRIVILEGED_GATE_WARNING/SPEC.md).
