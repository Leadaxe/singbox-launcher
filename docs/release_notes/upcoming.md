# Upcoming release — черновик

Сюда складываем пункты, которые войдут в следующий релиз. Перед релизом переносим в `X-Y-Z.md` и очищаем этот файл.

## EN
### Highlights
- **Domain rules work on Cloudflare sites with ECH, without FakeIP.** Chrome took an ECH config from the DNS HTTPS record and hid the site name, so a domain rule missed and traffic went to the default route. New preset **Block HTTPS/SVCB records** (off by default, right after Traffic Processing) answers HTTPS/SVCB queries empty for all domains; the rule window's DNS tab has **Block HTTPS/SVCB records (no ECH)** for the rule's own domains — it turns on by itself when you first enter domains, and is available for SRS rules too.
- **A rule's DNS options now work with ports, protocols and network.** A dedicated DNS server, Force IPv4, Fixed IP and Block HTTPS were unavailable for a rule with a port or network; they now apply to the rule's domains on any port and protocol, and the DNS tab says so.
- **Comments in a node's JSON source are kept.** `//`, `#` and `/* */` in text pasted into the JSON tab or the Origin field stay in the source as typed; Regen and backup import understand them, and a commented node still counts as authored. When a document is trimmed to its node arrays on save, the trimmed remainder is stored without comments.
- **A source or node whose hop is unavailable is no longer dropped.** If the detour target is not in the built config — the Direction is turned off, the node was deleted, renamed or vanished from its subscription, a template group no longer exists — the hop is removed, the nodes stay and connect directly, and the source gets a ⚠ naming the target and the nodes (`detour_unavailable`, contract 1.1.171). Before, all such nodes were excluded. A detour onto the node itself and detour loops still exclude the nodes; a chain with a missing position still drops out whole.
- **A preset DNS server can be chosen as Final DNS and Default domain resolver.** A server of an enabled preset (for example `russian:yandex_udp`) was offered in the dropdown, but Save answered "must be an enabled server tag": the check knew only your own servers. The check and the dropdowns now use the same set; a preset server switched off on the DNS tab is no longer offered.
- DNS tab: the server and rule lists sit in a rounded outlined panel with its own background and zebra rows, so a list reads as a block of its own rather than more of the form; the scrollbar no longer covers buttons and rows.
- **A source folded into a group can be picked as a detour.** The detour picker got a third branch, **Replace groups**, listing the groups of other folded subscriptions and folders (Manual, Auto and Both; for Both the selector itself). A group whose own nodes connect back through this source is shown with ⚠ and cannot be picked. The chain hop picker follows the same list: the `-auto` twin is no longer offered separately.

### Technical / Internal
- Contract 1.1.173 (D-150): preset `block-https` (`num` 10), rule field `rules[].dns.blockHttps`; per-rule DNS order Block HTTPS → Force IPv4 → server / Fixed IP; registry list `rule_dns_mirror_gate` replaced by `rule_dns_mirror_unseen` (keys not copied, no longer blocking) and new `rule_dns_block_https_domains`; corpus `rule_dns` +7 cases.
- Contract 1.1.172: comments (`//`, `#`, `/* */`) in a JSON node source are allowed and kept as typed; every reader strips them before parsing (`internal/jsonfmt.StripComments`), backup dedup compares the source without them.
- Contract 1.1.171: new warning code `detour_unavailable` (params `target`, `count`, `tags`), `source_detour_missing` removed; the build report kind `target_missing` is gone (a stripped hop is an `emit_degraded` entry with the code).

## RU
### Основное
- **Правила по доменам срабатывают на сайтах Cloudflare с ECH и без FakeIP.** Chrome брал ECH-конфиг из HTTPS-записи DNS и прятал имя сайта — правило по доменам промахивалось, трафик уходил по маршруту по умолчанию. Новый пресет **Block HTTPS/SVCB records** (выключен по умолчанию, сразу после Traffic Processing) отвечает на HTTPS/SVCB-запросы пустым для всех доменов; во вкладке DNS окна правила — **Block HTTPS/SVCB records (no ECH)** для доменов самого правила: включается сам при первом вводе доменов, доступен и SRS-правилам.
- **DNS-настройки правила работают с портами, протоколами и network.** Свой DNS-сервер, Force IPv4, Fixed IP и Block HTTPS были недоступны правилу с портом или network; теперь они действуют на домены правила при любом порте и протоколе, вкладка DNS об этом говорит.
- **Комментарии в JSON-исходнике узла сохраняются.** `//`, `#` и `/* */` в тексте, вставленном на вкладке JSON или в поле Origin, остаются в исходнике как набраны, Regen и импорт бэкапа их понимают; узел с комментариями по-прежнему считается авторским. Если документ при сохранении обрезается до узловых массивов, обрезанный остаток хранится без комментариев.
- **Источник или узел с недоступным хопом больше не выбрасывается.** Если цели detour нет в собранном конфиге — Направление выключено, узел удалён, переименован или пропал из подписки, группы шаблона больше нет, — хоп снимается, узлы остаются и подключаются напрямую, а у источника ⚠ с целью и узлами (`detour_unavailable`, контракт 1.1.171). Раньше такие узлы исключались все. detour узла на самого себя и кольца detour по-прежнему исключают узлы; цепочка с пропавшей позицией по-прежнему выпадает целиком.
- **DNS-сервер пресета можно выбрать как Final DNS и Default domain resolver.** Сервер включённого пресета (например `russian:yandex_udp`) был в выпадающем списке, но Save отвечал «must be an enabled server tag»: проверка знала только собственные серверы. Теперь проверка и списки берут один набор; сервер пресета, выключенный галочкой на вкладке DNS, в списки не попадает.
- Вкладка DNS: списки серверов и правил лежат в скруглённой рамке со своим фоном и зеброй — список читается как отдельный блок, а не продолжение формы; полоса прокрутки больше не ложится на кнопки и строки.
- **Источник, свёрнутый в группу, можно выбрать как detour.** В пикере detour появилась третья ветка **Replace groups** — группы других свёрнутых подписок и папок (Manual, Auto и Both; у Both — сам селектор). Группа, узлы которой сами подключаются через этот источник, показана с ⚠ и не выбирается. Пикер позиций цепочки берёт тот же список: двойник `-auto` отдельно больше не предлагается.

### Техническое / Внутреннее
- Контракт 1.1.173 (D-150): пресет `block-https` (`num` 10), поле правила `rules[].dns.blockHttps`; порядок DNS-правил правила Block HTTPS → Force IPv4 → сервер / Fixed IP; список реестра `rule_dns_mirror_gate` заменён на `rule_dns_mirror_unseen` (ключи не копируются и больше не блокируют) и новый `rule_dns_block_https_domains`; корпус `rule_dns` +7 кейсов.
- Контракт 1.1.172: комментарии (`//`, `#`, `/* */`) в JSON-исходнике узла разрешены и хранятся как набраны; каждый читатель снимает их перед разбором (`internal/jsonfmt.StripComments`), дедуп импорта сравнивает исходник без них.
- Контракт 1.1.171: новый код предупреждения `detour_unavailable` (параметры `target`, `count`, `tags`), `source_detour_missing` снят; вид записи отчёта сборки `target_missing` убран (снятый хоп — запись `emit_degraded` с кодом).
