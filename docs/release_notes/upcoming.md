# Upcoming release — черновик

Сюда складываем пункты, которые войдут в следующий релиз. Перед релизом переносим в `X-Y-Z.md` и очищаем этот файл.

## EN
### Highlights
- **Tunnel ingress protection.** A client tunnel is a two-way channel: the server on the other side of a WireGuard/AWG, OpenVPN or OpenConnect node (and a Tailscale peer) could open connections to your router, your LAN or the internet through you, because the core's userspace stack accepts packets for any address. The new **Tunnel ingress** preset (on by default, added once to existing setups, placed right after the locked head of the rules) rejects every connection arriving from such a tunnel, except what the node allows: the node window of these types gets **Allow access to this device** (services on the tunnel address; they see the peer as `127.0.0.1`), **Expose local network** (private networks) and **Allow as gateway** (anything, through the outbound chosen in the preset, `proxy-out` by default). Peers that are not gateways also get their DNS queries rejected. The preset's lists show which endpoints are covered and can be extended by hand. `advertise_routes` / `advertise_exit_node` of Tailscale only announce you — the switch decides. Contract 1.1.126, `TEMPLATE_LANG` §6.5.2, decision D-134.
- **"Skip presets" is now "Skip Tailscale presets".** The node field `skip_presets` became `skip_tailscale_presets`, is shown for Tailscale nodes only and affects only the `tailscale` preset — it can no longer switch off the tunnel protection. Old `state.json` files and backups with `skip_presets` are read as before; only the new key is written.
- **Homebrew on macOS:** `brew install --cask leadaxe/tap/singbox-launcher`. The Cask lives in [Leadaxe/homebrew-tap](https://github.com/Leadaxe/homebrew-tap) and follows stable releases on its own; the install script stays the recommended option.
- **macOS release ZIPs keep the executable bit.** The launcher binary was packed as `0644`, so an app extracted by hand did not start without `chmod +x`.
- **Template language: short `#if` form.** `{"#if": [cond, value, else]}` is now the canonical spelling; the long `{"#and": […], "#value": …, "#else": …}` form is still read indefinitely, and the stock template is rewritten to the short form with byte-identical output. A `#do` operation in a node loop can be conditional: `{"#if": [cond, {"#append": "@node"}]}` skips nodes where the condition is false. Contract 1.1.125, `TEMPLATE_LANG` §4.1 / §6.7.1, decision D-133.
- **DNS rule editor no longer drops `rule_set` references.** Opening "Edit DNS Rule" rebuilt the JSON from the form, whose picker held one value from a fixed list, so `"rule_set": ["user:custom", "user:dpi"]` came back as nothing (or as its first tag). The picker is now a multi-select, keeps tags that are not in the list (a disabled rule, a hand-written tag) and a server that is not enabled, and edits made in the JSON tab carry over to the form instead of being overwritten. Fields of the other rule type are cleared only when you switch the type yourself ([#140](https://github.com/Leadaxe/singbox-launcher/issues/140)).
- **A preset's DNS rule now appears where its routing rule stands.** Routing rules live on a numbered axis, DNS rules are ordered by hand, and a newly enabled preset's DNS rule used to be appended after every DNS rule you already had. For the new **Tunnel ingress** preset that meant its DNS reject landed behind the FakeIP catch-all (`A/AAAA → fakeip`) on existing setups, so closed tunnel peers still had their DNS answered although their connections were rejected. A preset's DNS rule is now inserted in front of the first preset DNS rule with a higher routing number (late defaults, presets enabled from the library, backups that lack the entry, the Debug API and a build that runs before the first save alike); your own DNS rules and the rules already in the list are not moved. Fresh installs are unchanged. Contract 1.1.127, `TEMPLATE_LANG` §6.10, decision D-135.
- **Core builds for linux/386 and linux/riscv64.** "Download core" now finds them for a machine whose daemon has not reported its platform yet, `riscv64` is offered in the machine and Target architecture lists (Target also gains `mips`/`mipsle`), and a Linux machine on 386 or riscv64 without a passport defaults to the procd service recipe, as these builds target OpenWrt. A machine whose daemon reports `packed` (core 1.14.3-lx.21+, the running core is UPX-packed) gets the `.upx.tar.gz` copy from "Download core", saved as `…-upx` beside the plain one; if the release has no packed copy, the plain binary is downloaded with a warning that it is 4–5 times larger.

- **The "Split all traffic 50/50" preset is gone.** It was no longer relevant; a saved rule that referenced it is kept disabled with a warning rather than lost.

### Technical / Internal
- The `#if` body is parsed in one place (`core/template/if_form.go`); map-spread, array-element, `EvalIfScalar`, `default_value`, the load validator and `#do` all go through it. Corpus: 28 new cases (`short_*`, `do_if_*`), paired with the long form.
- `state.PresetDNSSlotIndex` is the single place that computes where a new preset DNS slot goes; `SyncDNSOptionsWithActivePresets`, the DNS tab's `ReconcileDNSRuleOrder` and `ResolveDNS` (which now walks a synced copy of `dns.rules` instead of appending unlisted presets at the end) all use it. One named test: `TestLatePresetDNSRuleTakesAxisPosition`.
- Node record fields travel as one `configtypes.NodeRecordFlags` (state → emission → build cache → `template.PresetNode.Record` → `@node.<field>`), instead of a per-field map. Corpus: `for_each_node*` cases renamed to `skip_tailscale_presets`, new `tunnel_ingress_mixed` / `tunnel_ingress_no_nodes`.

## RU
### Основное
- **Защита от входящих из туннеля.** Клиентский туннель — двусторонний канал: сервер на той стороне узла WireGuard/AWG, OpenVPN или OpenConnect (и пир Tailscale) мог открыть соединение к роутеру, в вашу LAN или в интернет через вас — userspace-стек ядра принимает пакеты на любой адрес. Новый пресет **Tunnel ingress** (включён по умолчанию, у существующих настроек появляется один раз, стоит сразу после запертой головы правил) отклоняет всё, что приходит из такого туннеля, кроме разрешённого узлом: в окне узла этих типов переключатели **Allow access to this device** (сервисы на туннельном адресе; пира они видят как `127.0.0.1`), **Expose local network** (частные сети) и **Allow as gateway** (всё, через outbound, выбранный в пресете, по умолчанию `proxy-out`). Пирам, которые не шлюз, отклоняются и DNS-запросы. Списки пресета показывают, какие endpoint'ы закрыты, и дополняются руками. `advertise_routes` / `advertise_exit_node` у Tailscale только анонсируют вас — пропускает переключатель. Контракт 1.1.126, `TEMPLATE_LANG` §6.5.2, решение D-134.
- **«Skip presets» стал «Skip Tailscale presets».** Поле узла `skip_presets` переименовано в `skip_tailscale_presets`, показывается только у узлов Tailscale и действует только на пресет `tailscale` — выключить им защиту туннеля больше нельзя. Старые `state.json` и бэкапы с `skip_presets` читаются как раньше, пишется только новый ключ.
- **Homebrew на macOS:** `brew install --cask leadaxe/tap/singbox-launcher`. Cask живёт в [Leadaxe/homebrew-tap](https://github.com/Leadaxe/homebrew-tap) и сам следует за стабильными релизами; install-скрипт остаётся рекомендуемым способом.
- **В macOS-архивах релиза у бинаря есть бит исполнения.** Бинарь лаунчера упаковывался как `0644`, и распакованное вручную приложение не запускалось без `chmod +x`.
- **Язык шаблонов: короткая форма `#if`.** `{"#if": [cond, value, else]}` — теперь канон; длинная `{"#and": […], "#value": …, "#else": …}` читается бессрочно, штатный шаблон переписан на короткую форму с байт-в-байт тем же конфигом. Операция `#do` обхода узлов может быть условной: `{"#if": [cond, {"#append": "@node"}]}` пропускает узлы, где условие ложно. Контракт 1.1.125, `TEMPLATE_LANG` §4.1 / §6.7.1, решение D-133.
- **Редактор DNS-правил больше не теряет ссылки `rule_set`.** «Edit DNS Rule» при открытии пересобирал JSON из формы, где выбор набора был одним значением из фиксированного списка, и `"rule_set": ["user:custom", "user:dpi"]` превращался в пустоту (или в первый тег). Теперь выбор множественный, теги не из списка (выключенное правило, ручной ввод) и невключённый сервер сохраняются, а правки на вкладке JSON переносятся в форму, а не затираются ею. Поля другого типа правила вычищаются только при ручной смене типа ([#140](https://github.com/Leadaxe/singbox-launcher/issues/140)).
- **DNS-правило пресета появляется там, где стоит его маршрутное правило.** Маршрутные правила живут на нумерованной оси, DNS-правила упорядочены вручную, и DNS-правило только что включённого пресета дописывалось после всех ваших DNS-правил. Для нового пресета **Tunnel ingress** это означало, что его DNS-reject у существующих настроек вставал за «ловящим всё» правилом FakeIP (`A/AAAA → fakeip`): закрытым пирам туннеля всё ещё отвечал DNS, хотя их соединения отклонялись. Теперь DNS-правило пресета вставляется перед первым DNS-правилом пресета с бо́льшим номером маршрута (поздние дефолты, включение из Library, бэкап без такой записи, Debug API и сборка до первого сохранения — одинаково); ваши DNS-правила и уже стоящие в списке не двигаются. Чистая установка не меняется. Контракт 1.1.127, `TEMPLATE_LANG` §6.10, решение D-135.
- **Сборки ядра linux/386 и linux/riscv64.** «Download core» находит их и для машины, чей демон ещё не сообщил платформу; `riscv64` есть в выборе архитектуры машины и вкладки Target (там же добавлены `mips`/`mipsle`); Linux-машина на 386 или riscv64 без паспорта по умолчанию получает рецепт службы procd — эти сборки под OpenWrt. Машина, чей демон сообщает `packed` (ядро 1.14.3-lx.21+, работающее ядро сжато UPX), получает в «Download core» копию `.upx.tar.gz` — файл с суффиксом `-upx` рядом с обычным; если сжатой копии в релизе нет, качается обычный бинарь с предупреждением, что он в 4–5 раз крупнее.
- **Пресет «Split all traffic 50/50» снят.** Он потерял актуальность; сохранённое правило с ссылкой на него остаётся выключенным с предупреждением, а не теряется.

### Техническое / Внутреннее
- Тело `#if` разбирается в одном месте (`core/template/if_form.go`); map-spread, элемент массива, `EvalIfScalar`, `default_value`, валидатор загрузки и `#do` идут через него. Корпус: 28 новых кейсов (`short_*`, `do_if_*`), парных с длинной формой.
- `state.PresetDNSSlotIndex` — единственное место, где считается позиция нового DNS-слота пресета; им пользуются `SyncDNSOptionsWithActivePresets`, `ReconcileDNSRuleOrder` DNS-вкладки и `ResolveDNS` (теперь обходит синхронизированную копию `dns.rules`, а не дописывает неучтённые пресеты в конец). Один именованный тест: `TestLatePresetDNSRuleTakesAxisPosition`.
- Поля записи узла едут одной структурой `configtypes.NodeRecordFlags` (состояние → эмиссия → кэш сборки → `template.PresetNode.Record` → `@node.<поле>`) вместо карты на каждое поле. Корпус: кейсы `for_each_node*` на `skip_tailscale_presets`, новые `tunnel_ingress_mixed` / `tunnel_ingress_no_nodes`.
