# Release notes — v2.3.7 (2026-10-09)

## EN

A patch release after v2.3.6. Core `sing-box-lx 1.14.2-lx.12` unchanged, contract 1.1.114 unchanged.

### Fixed
- Wizard → Rules: an SRS rule with many rule-set URLs no longer fails to download on a slow connection. The files of one rule are fetched one after another, and the whole group used to share a fixed 90-second limit, so a rule with 8+ URLs kept failing on the same file — every retry started over from the first one. The limit now grows with the number of files (60 s per file, at least 90 s), and the error dialog shows the URL that actually failed instead of the first one in the list.
- Wizard → Rules: the list keeps its scroll position after drag-and-drop reorder, edit or delete (it used to jump back to the top).

## RU

Патч-релиз после v2.3.6. Ядро `sing-box-lx 1.14.2-lx.12` и контракт 1.1.114 без изменений.

### Исправлено
- Мастер → Rules: SRS-правило с большим числом ссылок больше не падает с ошибкой загрузки на медленном канале. Наборы одного правила качаются по очереди, а вся группа делила фиксированные 90 секунд, поэтому правило с 8+ ссылками раз за разом обрывалось на одном и том же файле — каждая повторная попытка начинала с первого. Теперь лимит растёт с числом файлов (60 с на файл, не меньше 90 с), а окно ошибки показывает ссылку, которая реально не скачалась, а не первую в списке.
- Мастер → Rules: список сохраняет позицию прокрутки после перетаскивания, правки или удаления правила (раньше прыгал в начало).
